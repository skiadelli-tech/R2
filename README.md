# Robot R2: κώδικας, επέκταση Scratch και χειριστήριο

Υλικό για το εκπαιδευτικό ρομπότ **Polytech R2** (Arduino + Bluetooth BT24), για χρήση στην τάξη.

| Αρχείο | Τι είναι |
|---|---|
| `R2-code-id/R2-code-id.ino` | Ο κώδικας του ρομπότ (Arduino) |
| `robot-r2-ble.js` | Επέκταση για Scratch / TurboWarp |
| `drive_R2.html` | Σελίδα για οδήγηση του ρομπότ από κινητό, tablet ή υπολογιστή |
| `r2.sprite3` | Αντικείμενο (sprite) για Scratch με τη μορφή του ρομπότ, για προσομοίωση της κίνησής του στην οθόνη |

## Γρήγορη χρήση, χωρίς κατέβασμα

- **Σελίδα οδήγησης:** https://skiadelli-tech.github.io/R2/drive_R2.html
- **Επέκταση για TurboWarp (URL):** https://skiadelli-tech.github.io/R2/robot-r2-ble.js

Οι διευθύνσεις δείχνουν πάντα την τελευταία έκδοση.

## Τι νέο έχει αυτή η έκδοση

- **Κάθε ρομπότ έχει δικό του όνομα.** Στην πρώτη εκκίνηση, το ρομπότ διαβάζει τα 2 τελευταία ψηφία της διεύθυνσης Bluetooth και μετονομάζει μόνο του το module σε `R2-` και τα ψηφία (π.χ. `R2-A6`). Ίδιος κώδικας για όλα τα ρομπότ, καμία αλλαγή ανά ρομπότ.
- **Η επέκταση και η σελίδα δείχνουν ποιο ρομπότ είναι συνδεδεμένο** (π.χ. «Ρομπότ: A6»).
- **Νέα μπλοκ «στρίψε αριστερά / δεξιά»**. Το «κινήσου» έχει πλέον μόνο μπροστά και πίσω.
- **Το κόκκινο κουμπί stop του Scratch σταματά και το ρομπότ**, όπως και την παρακολούθηση γραμμής.
- Πιο γρήγορη απόκριση όταν ο αισθητήρας απόστασης δεν βλέπει εμπόδιο, και σωστό αναβόσβημα των φώτων στην παρακολούθηση γραμμής.

## Ανέβασμα του κώδικα στο ρομπότ

Χρειάζεται η βιβλιοθήκη **Adafruit NeoPixel**. Στο Arduino IDE ή στο Mind+ διαλέγετε πλακέτα **Arduino Uno**.

1. **Βγάλτε το module Bluetooth** από την πλακέτα. Μοιράζεται τις ίδιες γραμμές με το USB και εμποδίζει το ανέβασμα.
2. Συνδέστε το ρομπότ με USB και ανεβάστε το `R2-code-id.ino`.
3. **Βγάλτε το USB** και βάλτε το module Bluetooth, με τον μικρό διακόπτη **BT στο ON**.
4. Ανάψτε το ρομπότ **από την μπαταρία**, χωρίς να είναι συνδεδεμένο πουθενά, και περιμένετε περίπου 5 δευτερόλεπτα.
5. Στην πρώτη εκκίνηση ακούγονται **2 μπιπ**: το module πήρε το νέο του όνομα. Αυτό γίνεται μόνο μία φορά.
6. Κλείστε και ανοίξτε το Bluetooth του υπολογιστή ή του tablet, γιατί συχνά θυμάται το παλιό όνομα («BT24»).

Αν το ρομπότ δείχνει «??» αντί για τα ψηφία του, ξεκίνησε ενώ ήταν συνδεδεμένο ή με το USB στη θέση του. Αποσυνδεθείτε, κλείστε και ανοίξτε το από τον διακόπτη και περιμένετε λίγα δευτερόλεπτα πριν συνδεθείτε.

**Ρυθμίσεις στην αρχή του αρχείου:**
- `NAME_PREFIX = "R2-"`: το πρόθεμα του ονόματος.
- `AUTO_RENAME = true`: βάλτε `false` αν θέλετε να κρατήσει το module το όνομα που ήδη έχει.
- `ID_DIGITS = 2`: πόσα ψηφία της διεύθυνσης να δείχνει (βάλτε 4 αν δύο ρομπότ τελειώνουν στα ίδια).

## Επέκταση Scratch (TurboWarp)

1. Ανοίξτε το [TurboWarp](https://turbowarp.org/editor) σε **Chrome ή Edge**. Σε Firefox και Safari το Bluetooth δεν δουλεύει.
2. Επεκτάσεις > **Custom Extension**. Στην καρτέλα **URL** γράψτε `https://skiadelli-tech.github.io/R2/robot-r2-ble.js` ή, στην καρτέλα **Files**, φορτώστε το αρχείο `robot-r2-ble.js`.
3. Κάντε τικ στο **Run without sandbox**: η επέκταση το χρειάζεται για να έχει πρόσβαση στο Bluetooth.
4. Πατήστε «Σύνδεση» και διαλέξτε το ρομπότ σας (π.χ. `R2-A6`).

| Ομάδα | Μπλοκ |
|---|---|
| Κίνηση | κινήσου [μπροστά / πίσω], κινήσου … για … δευτ., στρίψε [αριστερά / δεξιά], στρίψε … για … δευτ., STOP |
| Φώτα & ήχος | κόρνα, πίσω LED (D9), μπροστινό RGB (D12), χρώμα RGB |
| Αισθητήρες | απόσταση (A0/D2), αφή (D11), φως (A4), ήχος (A6), εντόπισες γραμμή (A1/A2/A3) |
| Αυτονομία | παρακολούθηση γραμμής [ON / OFF] |
| Σύνδεση | συνδεδεμένο;, αναγνωριστικό ρομπότ |

## Σελίδα οδήγησης

Ανοίξτε τη διεύθυνση https://skiadelli-tech.github.io/R2/drive_R2.html (ή το αρχείο `drive_R2.html`) σε **Chrome ή Edge**, πατήστε «Σύνδεση» και διαλέξτε το ρομπότ. Δουλεύει σε υπολογιστή και σε tablet ή κινητό Android. Σε iPad και iPhone δεν δουλεύει, γιατί ο Safari δεν υποστηρίζει Bluetooth από ιστοσελίδες. Τα βέλη κινούν το ρομπότ όσο τα κρατάτε πατημένα. Τα κουμπιά ελέγχουν την κόρνα, τα φώτα και το χρώμα του μπροστινού LED.

Το Bluetooth του browser δουλεύει μόνο σε σελίδες **https** ή σε αρχεία ανοιγμένα από τον υπολογιστή.

## Εντολές Bluetooth (για όποιον θέλει να φτιάξει δική του εφαρμογή)

Το ρομπότ δέχεται χαρακτήρες μέσω BLE UART (service `FFE0`, characteristic `FFE1`).

| Εντολή | Τι κάνει | Απάντηση |
|---|---|---|
| `U` `D` `L` `R` | μπροστά, πίσω, στροφή αριστερά, στροφή δεξιά | |
| `Q` `E` | μπροστά-δεξιά, μπροστά-αριστερά | |
| `S` | σταμάτα | |
| `B` | κόρνα | |
| `t` / `u` | πίσω LED ON / OFF | |
| `f` / `g` | μπροστινό RGB ON / OFF | |
| `C` + `W R G B A P C` | χρώμα μπροστινού RGB | |
| `Z` / `z` | παρακολούθηση γραμμής ON / OFF | |
| `?` | απόσταση | `D:<cm>` (400 = κανένα εμπόδιο) |
| `Y` | αφή | `T:<0/1>` |
| `H` | φως | `L:<lux>` |
| `J` | ήχος | `S:<επίπεδο>` |
| `M` | γραμμή | `N:<0/1>` |
| `I` | ταυτότητα ρομπότ | `I:<ψηφία>` |

Οι εντολές κίνησης πρέπει να επαναλαμβάνονται κάθε λίγο: αν δεν έρθει καμία εντολή για 0,9 δευτερόλεπτα, το ρομπότ σταματά για ασφάλεια.
